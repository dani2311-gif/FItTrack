# FitTrack - Código fuente

Proyecto extraído del archivo original FitTrack-codigo.zip.

## Estructura principal
- src/routes/: pantallas y módulos de la aplicación.
- src/components/fittrack/: componentes propios de FitTrack.
- src/components/ui/: componentes de interfaz reutilizables.
- src/lib/: lógica auxiliar y datos del proyecto.
- src/hooks/: hooks de la aplicación.
- Archivos raíz: configuración de Vite, TypeScript, Bun y dependencias.

## Módulos principales
- dashboard.tsx
- estudiantes.tsx
- profesores.tsx
- evaluaciones.tsx
- reportes.tsx
- pruebas.tsx
- login.tsx

Este paquete conserva los archivos de código y configuración presentes en el ZIP original.
