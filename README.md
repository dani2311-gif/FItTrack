
FitTrack es un sistema digital de seguimiento del rendimiento físico, diseñado para el Instituto Universitario de Caldas. Su objetivo principal es facilitar el registro, control y análisis de las capacidades físicas de los estudiantes durante el año escolar. La plataforma permite a los docentes gestionar evaluaciones, consultar estadísticas, observar el progreso de cada estudiante y generar reportes, ayudando a mejorar el seguimiento de la actividad física y el desempeño deportivo dentro de la institución.
